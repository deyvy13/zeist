<Callout type="success" title="Resposta rápida">
Depende do que você vai construir. Para uma rotina LISP ou um script curto basta um chat como ChatGPT, Claude ou Gemini. Para um plugin em C# do Revit ou do Civil 3D convém uma ferramenta que trabalhe sobre o projeto inteiro: GitHub Copilot no Visual Studio, Cursor, Claude Code ou Codex. Nenhuma substitui testar com os seus projetos.
</Callout>

<Callout type="info" title="Glossário: os termos que você vai ler, em linguagem simples">
- **Vibe coding** — Programar descrevendo em linguagem comum o que você quer, enquanto a IA escreve o código.
- **Chat** — A janela de conversa do ChatGPT, do Claude ou do Gemini, no navegador.
- **Editor de código** — O programa onde se escreve e se organiza o código, como o Visual Studio ou o VS Code.
- **Agente de código** — Uma IA que lê todo o seu projeto, edita arquivos, compila e corrige erros por conta própria.
- **Plugin** — Um programa que se instala dentro do Revit ou do Civil 3D e acrescenta botões na barra superior.
</Callout>

## Que tipos de ferramentas de vibe coding existem?

| Tipo | Exemplos | Como trabalha | Para que serve |
|---|---|---|---|
| Chat | ChatGPT, Claude, Gemini | Você pede o código e copia | Rotinas curtas, fórmulas, macros |
| Assistente no editor | GitHub Copilot (VS Code e Visual Studio), Cursor | Sugere e edita dentro do arquivo aberto | Projetos médios, aprender enquanto programa |
| Agente de código | Claude Code, Codex, o modo agente do Copilot ou do Cursor | Lê o projeto inteiro, edita vários arquivos, compila e corrige | Plugins completos e ferramentas com várias partes |

O que muda de um tipo para outro não é o quanto a IA é inteligente, e sim **quanto do projeto ela enxerga e quanto consegue fazer sozinha**.

## Qual convém para cada tarefa de engenharia?

| O que você quer construir | Ferramenta que melhor se encaixa | Por quê |
|---|---|---|
| Rotina LISP para AutoCAD ou Civil 3D | Um chat e o VS Code com a extensão de AutoLISP | É um arquivo curto; o editor serve para depurá-lo |
| Macro do Excel ou script de Python | Um chat ou o Cursor | Cabe em um ou dois arquivos |
| Nó de Python dentro do Dynamo | Um chat | Você cola o código no nó e testa no grafo |
| Plugin em C# para Revit ou Civil 3D | Visual Studio com GitHub Copilot, ou Claude Code ou Codex sobre a pasta do projeto | São vários arquivos, referências à API e compilação |
| Ferramenta web (calculadora, painel) | Cursor, Claude Code ou Codex | Muitas peças que o agente monta e testa |

No plugin, a IA escreve e compila, mas **o teste é seu**: carregá-lo no Revit ou no Civil 3D, rodar sobre um modelo real e conferir o resultado.

## Quais têm versão gratuita?

- **Os chats** do ChatGPT, do Claude e do Gemini têm planos gratuitos com limites de uso.
- **O GitHub Copilot** tem um plano gratuito com funções limitadas, que funciona no VS Code e no Visual Studio.
- **O Cursor** tem um plano gratuito, o Hobby.
- **O Codex** vem incluído nos planos do ChatGPT, com uso limitado nos mais básicos.
- **O Claude Code** precisa de um plano pago da Anthropic ou de uma chave de API.

Preços e limites mudam quase todo mês: confira no site de cada uma antes de decidir.

## O que cuidar com qualquer uma delas?

1. **Diga a sua versão.** A IA costuma escrever para versões antigas da API. Revit, AutoCAD e Civil 3D 2025 e 2026 usam .NET 8, e as 2027, .NET 10.
2. **Não envie informação confidencial** de clientes sem conferir a política de dados do seu plano.
3. **Trabalhe com controle de versões** (git): um agente pode mudar muitos arquivos de uma vez, e assim você consegue voltar atrás.
4. **Teste em cópias** dos projetos ou modelos, nunca no arquivo de produção.
5. **Aprenda a ler o que ela gera.** É o que separa quem termina uma ferramenta de quem fica travado. Explicamos no [guia de vibe coding para engenheiros](/pt/blog/vibe-coding-para-engenheiros).
